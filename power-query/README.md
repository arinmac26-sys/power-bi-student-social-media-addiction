# Power Query Documentation

Recommended preparation steps:

1. Load both Excel sheets.
2. Promote headers.
3. Set numeric and text data types.
4. Trim and clean categorical text.
5. Check nulls.
6. Validate Student_ID uniqueness.
7. Validate referential integrity between the two tables.
8. Rename fields only when necessary.
9. Disable unnecessary automatic date/time behavior if using a dedicated DateTable.
10. Close & Apply.

Keep the final transformation steps documented here if you later change the PBIX.
