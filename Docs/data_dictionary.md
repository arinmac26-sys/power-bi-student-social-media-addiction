# Data Dictionary

## Student Details

| Field | Type | Description |
|---|---|---|
| Student_ID | Integer | Unique student identifier |
| Age | Integer | Student age |
| Gender | Text | Student gender |
| Academic_Level | Text | High School / Undergraduate / Graduate |
| Country | Text | Student country |
| Sleep_Hours_Per_Night | Decimal | Average sleep hours per night |
| Mental_Health_Score | Integer | Mental health score in the source dataset |
| Relationship_Status | Text | Relationship status |
| Conflicts_Over_Social_Media | Integer | Number of reported conflicts |
| Addicted_Score | Integer | Social-media addiction score |
| Health_Band | Text | Calculated analytical band in the PBIX |
| Conflict_Level | Text | Calculated analytical band in the PBIX |

## Platform Details

| Field | Type | Description |
|---|---|---|
| Student_ID | Integer | Student key |
| Avg_Daily_Usage_Hours | Decimal | Average daily social-media usage |
| Most_Used_Platform | Text | Most-used social-media platform |
| Affects_Academic_Performance | Text | Whether social-media usage affects academic performance |
