# Project Walkthrough

## Phase 1 — Understand the data
Inspect source tables, row counts, field types, categorical values and numeric ranges.

## Phase 2 — Prepare data
Use Power Query to validate types, trim text, handle nulls and standardize categories.

## Phase 3 — Build model
Create and validate the Student_ID relationship. Keep the model simple and business-oriented.

## Phase 4 — Create metrics
Create core KPIs for student count, average usage, academic impact and average sleep.

## Phase 5 — Build report
Build six analytical pages:
- Executive Overview
- Mental Health & Lifestyle
- Academic Impact
- Relationships and Conflicts
- Interactive Story View
- Student Details

## Phase 6 — Validate
Cross-check KPI totals against the source Excel data and test slicer interactions.

## Phase 7 — Publish
Publish to Power BI Service, configure refresh if applicable, capture report screenshots and add the public link to README.
